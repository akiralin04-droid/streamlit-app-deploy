# 文字数カウント & BMI計算ツール

入力したテキストの文字数を数えたり、身長・体重からBMI値を計算したりする作業を、電卓や別サイトを使わずその場で行うためのツールです。

## 課題

- テキストの文字数を確認したい場合、Excelや文字数カウントサイトを別途開いて数える必要がある
- BMIを計算したい場合、計算式を自分で入力するか電卓を使う必要がある
- 入力ミス（未入力・数値以外の入力）に気づかないまま計算を進めてしまうことがある

## できること

- ラジオボタンで「文字数カウント」と「BMI値の計算」の動作モードを切り替えられる
- 文字数カウントモードでは、入力したテキストの文字数を表示する
- BMI計算モードでは、身長・体重を入力するとBMI値を算出して表示する
- テキストや身長・体重が未入力のまま実行した場合、入力を促すエラーメッセージを表示する
- 身長・体重に数値以外の値が入力された場合、エラーメッセージを表示する
- 身長に0以下の値が入力された場合、エラーメッセージを表示しゼロ除算を防ぐ

## 使用技術

- Python
- Streamlit

## 動かし方

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 設計上の工夫

- 動作モードの切り替え（ラジオボタン）と、入力欄・結果表示エリアを `st.divider()` で視覚的に分離している
- 数値以外の入力を `try/except` で捕捉し、`ValueError` 発生時にエラーメッセージを表示する
- 身長が0以下の場合を明示的に分岐させ、ゼロ除算エラーを防ぐガード処理を入れている
